# AI Usage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local AI Usage tray app at `/Volumes/MobileSSD/Program/My/ai-usage` that aggregates coding-agent parsers plus ChatGPT web A-caliber estimates, with a vibe-cafe-style dashboard minus cost.

**Architecture:** Tauri 2 tray shell (WebView destroyed when hidden) spawns a bundled Node sidecar on a 30-minute timer. Sidecar runs vibe-usage parsers plus `chatgpt-web`. Results upsert `~/.ai-usage/usage.db`. Chrome/Edge extension writes `~/.ai-usage/chatgpt-web.jsonl` via Native Messaging. Cloudflare Worker is optional and not required for the first runnable slice.

**Tech Stack:** Node ≥20 (sidecar, parsers, extension tests), Tauri 2 + Vite/React, rusqlite, Chrome MV3, Rust native host.

**Spec:** `docs/superpowers/specs/2026-09-09-ai-usage-design.md` (copy into the ai-usage repo as well)

## Global Constraints

- Product name AI Usage; binary/repo `ai-usage`; extension AI Usage · ChatGPT
- Data dir `~/.ai-usage/` (Windows `%USERPROFILE%\.ai-usage`); never read/write `~/.vibe-usage`
- ChatGPT source `chatgpt-web`; A口径 = visible user `inputTokens` + visible assistant `outputTokens`; ignore `estimated_context_input_tokens` for buckets; `reasoningOutputTokens` = 0; `project` = `chatgpt`
- `activeSeconds` for ChatGPT = sum of `thinking_seconds` on model steps, not extractSessions turn gaps
- Strip `text` before storage/jsonl/cloud
- No cost card, no quota cards, no Electron, Node sidecar must exit after sync
- Platforms: Win11 NSIS, macOS DMG, Ubuntu 22.04+ `.deb` (packaging is a later task; develop on the current Mac first)
- Dashboard views: 编程工具 | ChatGPT | 全部; toggle「ChatGPT 估算计入总 Token」default on; toggle only affects 全部 + tray
